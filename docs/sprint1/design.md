# Diseño del Sprint 1: login y cuentas de usuario

## Diseño visual
- Colores en tonos azul y gris
- Bootstrap 5 y CSS
- Fuente Arial; títulos en Arial bold
- Los campos vacíos o inválidos se marcan en rojo

## vistas
- Login: formulario con correo y contraseña
- Lista de usuarios: visible solo para administrador
- Formulario de usuario: crear y editar (nombre, correo, rol, estado activo)

## Datos
- Tabla usuarios: id, nombre, correo, contrasena_hash, rol, activo
